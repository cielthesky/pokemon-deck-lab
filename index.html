사진으로 덱 등록

카드를 겹치지 않게 펼쳐 찍거나 덱 리스트 화면을 캡처하세요. 여러 장도 됩니다. 인식 결과는 아래 텍스트 칸에 들어가며, 확인한 뒤 “이 텍스트로 덱 교체”를 누르면 적용됩니다.

Anthropic API 키 설정

키는 이 기기의 브라우저에만 저장되고 Anthropic API로만 전송됩니다. 다른 사람과 같이 쓰는 기기라면 사용 후 지우세요. 키는 console.anthropic.com에서 발급합니다.

덱 리스트 가져오기 / 내보내기

한 줄에 한 카드씩 “리자몽 ex 3장”, “4 하이퍼볼” 형식으로 적으세요. 띄어쓰기는 무시하며, 영문 PTCGL 리스트(“4 Charmander PAF 7”)도 한글 이름으로 바꿔 읽습니다. 모르는 카드는 미등록으로 표시되니 이름을 눌러 역할을 지정하세요.

상대 없이 혼자 전개해서(골드피시) 몇 번째 내 턴에 목표 데미지로 공격할 수 있는지 측정합니다. 대상은 내 덱입니다.

카드 1장을 빼고 다른 카드 1장을 넣는 교체를 반복하며 목표 점수가 오르는 구성을 찾습니다. 🔒 잠금한 카드는 장수를 바꾸지 않습니다.

넣어 볼 수 있는 후보 카드

두 덱을 같은 규칙의 자동 플레이로 붙입니다. 선공은 매 판 무작위입니다.

시뮬레이션 모델 — 카드 원문 대신 카드마다 지정한 역할로 플레이합니다.
  • 에너지는 타입 구분 없이 장수만 셉니다. 기술은 카드당 하나(가장 강한 것)만 씁니다.
  • 자동 플레이는 서치 → 진화 → 서포트 → 에너지 → 교체 → 보스 → 공격 순의 정해진 판단을 따릅니다. 실제 숙련자보다 단순합니다.
  • 특수 상태, 도구·스타디움 효과, 회복, 상대 특성 방해는 반영하지 않습니다. 결과는 장수 비교·경향 파악용으로 보세요.
